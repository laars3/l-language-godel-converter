# L-Program Coder / Decoder

A web app that encodes and decodes programs written in the theoretical language 'L', built for Professor Fechter's Theory of Computation course.

A Gödel number encodes a piece of syntax, here a whole program, as a single number, built so it can always be decoded back. This app computes that number for an L-program, or reverses one back into the program, showing every step either way.

Written in Python, running entirely client-side through PyScript, no server, no build step.
